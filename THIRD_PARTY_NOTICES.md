# Componente terțe

Fișierele `rtl/kcpsm6.v`, `software/ROM_form.v`, memoria generată `software/demo.v` și executabilele din `tools` provin din distribuția Xilinx KCPSM6 folosită în proiectul original. Antetele și condițiile originale rămân aplicabile; publicarea acestui repository nu le relicențiază. Nucleul este destinat dispozitivelor Xilinx.

`docs/Basys-3-Master.xdc` provine din repository-ul oficial Digilent/digilent-xdc. Constrângerile active sunt adaptate în `constraints/Basys3.xdc`.
